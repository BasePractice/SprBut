## Что в презентации

> Реактивный стек поверх Netty, Servlet API не обязателен. `Mono` — ноль или
> один элемент, `Flux` — поток из многих. Неблокирующий ввод-вывод: поток
> не простаивает в ожидании. `WebClient` вместо `RestTemplate`, ответ — снова
> `Mono` или `Flux`. Функциональные маршруты: `RouterFunction`
> и `HandlerFunction`. Backpressure: потребитель сам задаёт темп поставки
> данных. Один блокирующий вызов внутри цепочки сводит выигрыш к нулю.

Модуль — прямое продолжение [модуля 20](../20-spring-mvc/README.md): те же
задачи, другая модель выполнения.

## Расширенный пример

[`Demand`](src/main/java/ru/sprbut/m21/extended/Demand.java) — backpressure,
показанный не на словах.

Подписчик просит ровно столько элементов, сколько готов принять, и источник
отдаёт ровно столько — ни одним больше, даже если элементов у него в тысячу
раз больше. Счётчик на источнике доказывает, что лишние элементы не просто
не доехали, а не были произведены.

Это и есть ответ на вопрос, чем поток отличается от коллекции: коллекцию
отдают целиком и сразу, поток — по запросу потребителя. Без такого договора
быстрый источник переполнил бы медленного получателя, и вся разница между
«медленно» и «упало» свелась бы к размеру буфера.

## Ключевые выводы

* `Flux` — это рецепт, а не блюдо: пока никто не подписался, не выполняется
  ничего. Метод контроллера завершается задолго до появления данных.
* Пустой `Mono` — не ошибка, а законное отсутствие значения, и сам по себе
  он даёт ответ 200 с пустым телом. Код 404 приходится назвать явно.
* `Flux<String>` не станет JSON-массивом ни при каком `produces`:
  `CharSequence` кодируется раньше, чем до дела дойдёт Jackson. Массивом
  поток становится, только если его элемент — объект.
* Функциональный маршрут — обычный объект, а не метаданные: его можно собрать
  в цикле, передать в метод, склеить с другим. Аннотация так не умеет.
* Событийных потоков всего по числу ядер, и ни один не имеет права
  блокироваться. Один вызов блокирующего JDBC внутри цепочки отнимает больше,
  чем даёт весь реактивный стек — тогда честнее остаться на модуле 20.
